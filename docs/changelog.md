The contract-visible ones: **override-map keys are now resolved canonically everywhere** — `disabledSlots`/`slotCapacity` were looked up with `===`/`includes` while the booked-count matcher already matched canonically, so a cap or block whose key spelling drifted from the configured slot value was counted and rendered "Full" on the dashboard but **never enforced at checkout** (new `findSlotOverrideKey`, exact spelling wins a tie — [ADR-13](./decisions.md)); the **lenient read now prunes orphan override keys** instead of keeping entries the strict whole-map write rejects — one orphan permanently bricked the day-override editor and slot delete with no in-app way to remove it; and `countsMeta` gains a **`"partial"` status** — both scan caps (pages per date chunk, tracked dates) previously only `console.warn`ed while the meta still said `"ok"`, i.e. silently under-counted counts reported as healthy; `/app/scheduler` now shows a warning banner naming the cap + affected dates, and the orders/create webhook logs it.
